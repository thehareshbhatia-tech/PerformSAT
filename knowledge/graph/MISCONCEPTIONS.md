# Misconception Index — tutor diagnostic backbone

738 named misconceptions across 178 nodes, each with its formation cause. Primary artifact for tutor prompt injection: when a student misses an item mapped to a node, the tutor loads that node's misconceptions + diagnostic indicators to name the ROOT CAUSE, not just mark wrong. Regenerated by `node scripts/buildGraphIndexes.mjs`.

Format: `node-id` → **misconception-id** — belief & why it forms (first sentence).
