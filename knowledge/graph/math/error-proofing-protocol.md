# Error-proofing: the four silly-mistake causes and their counters

## What it is
A taxonomy of the careless errors that cost more scaled points than hard-question ignorance — the adaptive test weights easy items heavily, so a slip on an easy question is the most expensive mistake on the section. Every "silly" miss traces to one of four causes, and each cause has a specific counter-habit.

## Mental model
**Silly mistakes aren't random — they come in exactly four flavors, and each has an antidote you drill until it's automatic.** (1) Misreading or forgetting part of the ask, (2) mistransferring data between screen, scratch paper, and answer box, (3) mechanical algebra slips like an undistributed negative, (4) misremembered formulas.

## Expert reasoning process
1. **Reread the final sentence before locking in** — the single highest-value habit; it catches "solved for x, asked for 2x" and "asked for the width, found the length" misreads at the moment they're cheapest to fix.
2. **Point-check every transfer**: each time a number moves (question → Desmos, Desmos → paper, paper → answer box), glance back at the source. Transfer errors and misreads are the most common AND the easiest to eliminate.
3. **Two-route verification when time allows**: confirm algebra with a 5-second Desmos plot, a regression, or plugging the answer back in. Different method, same answer = near-certain correct. Skip it when the clock is tight — verification is a luxury budgeted after coverage.
4. **Make the checks automatic in practice, not test day**: run the reread + transfer-check ritual on every drill question so it costs zero willpower under pressure.

## Misconceptions
- **"careless = unfixable personality trait"** — students treat slips as bad luck instead of a process gap with named counters; the fix is ritual, not vigilance.
- **verification-always** — burning pacing on triple-checks of easy items; verification is conditional on time remaining, the reread is not.

## Diagnostic indicators
- Wrong answer equals an intermediate value of the correct work (found x, asked for x+3) → cause 1; prescribe the final-sentence reread.
- Wrong answer differs from correct by a single digit/sign transposition → cause 2; prescribe transfer point-checks.
- Easy-item accuracy notably below medium-item accuracy → process gap, not knowledge gap; teach this protocol before any content.
